# Secret Life of a MAUI Page

This repository contains a .NET MAUI demo app created for the **"Secret Life of a MAUI Page"** session at **MAUI Day Skopje 2026**.

Presented by **Mihajlo Mladenov**.

## Purpose

The demo is intended to show how a MAUI page behaves throughout its lifetime, including navigation, appearance, disappearance, and related application events.

## Project

The sample app lives in this repository as `PageLifecycleLab` and can be built and run as a standard .NET MAUI application.
